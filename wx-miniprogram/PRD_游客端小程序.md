# PRD 文档 — Nature Haven Camp 游客端小程序

## 一、产品概述

| 项目 | 内容 |
|------|------|
| 产品名称 | Nature Haven Camp 游客端 |
| 产品定位 | 营地游客的移动端服务助手 |
| 目标用户 | 到访营地的游客、计划来营地的潜在游客 |
| 核心价值 | 让游客随时随地浏览活动课程、在线报名、提交反馈，提升营地体验 |

---

## 二、功能描述

### 2.1 功能清单

| 编号 | 功能模块 | 功能点 | 优先级 | 说明 |
|------|----------|--------|--------|------|
| F01 | 微信登录 | 授权微信登录 | P0 | 游客首次使用通过微信授权自动注册/登录 |
| F02 | 活动浏览 | 查看活动课程列表 | P0 | 展示所有可报名的营地活动课程 |
| F03 | 活动详情 | 查看单个活动完整信息 | P0 | 活动标题、日期、地点、名额进度、详细介绍 |
| F04 | 活动报名 | 在线报名活动 | P0 | 填写姓名、手机号完成报名 |
| F05 | 取消报名 | 取消已报名的活动 | P1 | 在活动详情页可取消报名 |
| F06 | 我的报名 | 查看个人报名记录 | P1 | 按时间倒序展示所有报名记录 |
| F07 | 提交反馈 | 提交体验反馈 | P0 | 游客可对营地体验提出意见或建议 |
| F08 | 名额进度 | 实时显示活动名额 | P0 | 已报名人数/总名额的进度条展示 |

### 2.2 实现范围

**本期实现（v1.0）：**
- 微信登录授权
- 活动课程浏览与详情查看
- 活动在线报名与取消
- 个人报名记录管理
- 游客反馈提交

**本期不实现：**
- 在线支付（后续版本考虑）
- 活动评价/评分系统
- 消息推送
- 分享邀请
- 客服聊天

`

**页面元素说明：**

| 元素 | 说明 | 交互 |
|------|------|------|
| 顶部导航栏 | 显示活动标题 + 返回按钮 | 点击返回上一页 |
| 活动信息卡片 | 标题、状态、日期、地点、名额进度 | — |
| 活动介绍卡片 | 完整活动描述文本 | — |
| 报名表单 | 姓名输入 + 手机号输入 + 确认按钮 | 点击提交报名 |
| 已报名状态 | 显示"✅ 您已报名该活动" + 取消按钮 | 点击取消报名 |
| 不可报名状态 | 显示"❌ 活动已满员"或"⏰ 活动已结束" | — |

**状态说明：**

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 可报名 | 活动状态=报名中 + 有名额 + 未报名 | 报名表单（姓名+手机号+确认按钮） |
| 已报名 | 当前用户已报名该活动 | "✅ 您已报名该活动" + 取消报名按钮 |
| 已满员 | 活动状态=已满员 | "❌ 活动已满员" |
| 已结束 | 活动状态=已结束 | "⏰ 活动已结束" |

**交互流程 - 报名：**
1. 游客填写姓名和手机号
2. 点击"确认报名"按钮
3. 系统校验：姓名不为空、手机号格式正确（11位手机号）
4. 校验通过 → 显示"报名成功"提示 → 页面刷新显示已报名状态
5. 校验失败 → 弹出提示告知具体原因

**交互流程 - 取消报名：**
1. 点击"取消报名"按钮
2. 弹出确认弹窗："确定要取消报名吗？"
3. 点击"确定" → 取消成功 → 页面刷新显示可报名状态
4. 点击"取消" → 关闭弹窗，不做任何操作

## 四、全局设计规范

### 4.1 视觉风格

| 规范 | 内容 |
|------|------|
| 设计主题 | 森系深绿自然风 |
| 主色调 | 深绿 #07110d / 金色 #d6b56d |
| 辅助色 | 草绿 #8fa96f / 米白 #f3efe4 |
| 字体 | 系统默认无衬线字体 |
| 圆角 | 大圆角 28rpx |
| 卡片风格 | 毛玻璃半透明效果 |
| 图标风格 | Emoji 图标 |

### 4.2 交互规范

| 场景 | 交互方式 |
|------|----------|
| 页面跳转 | 原生导航（navigateTo） |
| 表单提交 | 按钮加载态 + Toast 提示 |
| 数据加载 | 页面级 loading 提示 |
| 错误提示 | Toast 轻提示（icon: none） |
| 成功提示 | Toast 成功提示（icon: success） |
| 确认操作 | Modal 弹窗确认 |

### 4.3 异常处理

| 场景 | 处理方式 |
|------|----------|
| 网络错误 | Toast 提示"网络错误" |
| 接口异常 | Toast 显示后端返回的错误信息 |
| 表单校验失败 | Toast 提示具体校验规则 |
| 空数据 | 显示空状态提示文案 |

## 五、非功能性需求

| 需求 | 说明 |
|------|------|
| 兼容性 | 支持 iOS 和 Android 微信客户端 |
| 加载速度 | 首页首屏加载不超过 3 秒 |
| 数据安全 | 用户手机号仅用于报名确认，不对外展示 |
| 隐私保护 | 用户信息仅存储 openid，不收集其他隐私数据 |
